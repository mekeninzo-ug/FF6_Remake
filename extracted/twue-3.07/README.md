# TWUE v3.07 + Bug Fixes extraction

This folder was extracted directly from the verified 4 MiB patched ROM using the FF6 U.S. maps/decoders with patched pointer adjustments. It does not reuse vanilla files as substitutes. `assets/`, `build/en/`, `audio/`, `event/`, and `provenance/` contain mapped exports; `expanded/` preserves the full added `$F0–$FF` banks and address-tagged text candidates.

See `../comparison/REPORT.md` for extraction boundaries, invalid pointer ranges, and the comparison results. Battle-background raw pointer candidates are kept under `provenance/unclassified_pointer_data/` and labelled as unverified.
